# 하태형

### Backend Developer · Security & Infrastructure

백엔드 개발을 중심으로 인증·인가, 사용자 데이터 처리, 외부 의존성과 예외 상황을 다루는 기능을 구현합니다. 네트워크·보안 환경도 직접 구성해 동작을 확인하며, 프로젝트마다 담당 범위와 검증 방법을 기록합니다.

## 대표 프로젝트

### [HealthMe — 영양 큐레이션 쇼핑몰](https://github.com/HTH-0/Project_HealthMe)
Spring Boot 팀 프로젝트입니다. 로그인·회원가입, OAuth2 소셜 로그인, 계정 찾기, 설문 결과 분석과 영양소 기반 추천 로직을 담당했습니다. 팀 전체 기능과 제 담당 범위를 구분해 코드와 설계 근거를 정리했습니다.

### [PinPoint — 목표 관리 앱](https://github.com/HTH-0/aleph_pinpoint)
Next.js와 TypeScript 기반 개인 앱입니다. 목표·일정·연속 기록을 관리하고, 테마와 핀 모드를 구현했습니다. 데이터 모델, 쿼리, 완료 처리와 이력 관리, 테스트 실행 방법을 저장소에서 확인할 수 있습니다.

### [Sound Walk — 소리 단서 기반 3D 길찾기](https://github.com/HTH-0/aleph_thesis_app)
실제 지형 자료와 고정 청각 랜드마크 규칙을 적용한 3D 길찾기 앱입니다. 데이터 출처·라이선스, 재현 방법, 연구에서 확인하지 못한 한계를 함께 기록했습니다. [기반 논문과 분석 자료](https://github.com/HTH-0/aleph_thesis)

### [The Day Before — GitHub 데이터 기록 대시보드](https://github.com/HTH-0/aleph_the_day_before)
전날 생성된 공개 GitHub 저장소 수를 기록하고 추이를 보여 주는 앱입니다. API 실패 시 임의의 값을 만들지 않고, 마지막 정상 데이터와 오류 상태를 구분하며, 실패 시나리오를 실제 기록과 분리해 시험합니다.

### [Dodge — 브라우저 액션 게임](https://github.com/HTH-0/aleph_project_dodge)
JavaScript 기반 2D 회피 게임입니다. 여러 궤적의 장애물, 도전 모드, localStorage 저장, 설정과 접근성 옵션을 실험한 개인 프로젝트입니다.

## 기술 경험

- **백엔드:** Java, Spring Boot, Spring Security, OAuth2, JWT, JPA/MyBatis, SQL
- **웹 애플리케이션:** Next.js, TypeScript, JavaScript, Drizzle ORM, PostgreSQL
- **네트워크·보안 실습:** VLAN, OSPF, GNS3, VirtualBox, BIND9, OSSEC/Wazuh, Zabbix, Snort 3, pfSense/OpenVPN

프로젝트에서 사용한 기술과 과정 실습으로 다룬 기술을 구분해 설명합니다. 운영 환경에서 사용했다고 확인되지 않은 항목은 실무 경험으로 표현하지 않습니다.

## 작업 원칙

AI를 활용한 프로젝트에서는 AI가 작성한 코드와 제가 정한 요구사항·설계·선택·검증을 문서에서 구분합니다. 기능을 추가하는 것뿐 아니라 직접 사용해 필요 없는 기능을 제거하고, 실패 조건과 한계를 기록하는 것을 중요하게 생각합니다.
